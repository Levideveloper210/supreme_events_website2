# Supreme Events Website

A responsive, static multi-page website for Supreme Events in Owerri, Imo State. Built with plain HTML, CSS and JavaScript so it can be uploaded to GitHub and deployed on Vercel without a build step.

## Pages
- `index.html` — Home, services preview, and selected reviews
- `services.html` — Services
- `feedback.html` — Feedback and enquiry form
- `styles.css` — Responsive styling
- `script.js` — Mobile navigation, current year, and feedback form handling

## Deploy to GitHub and Vercel
1. Extract this ZIP file.
2. Create a new repository on GitHub.
3. Upload the files and folders inside this project (not the ZIP file itself). Make sure `index.html` is at the repository root.
4. In Vercel, choose **Add New → Project**, import the GitHub repository, and deploy.
5. For a plain HTML site, leave the framework preset as **Other** and do not set a build command or output directory. Deploy.

## Important feedback-form note
The feedback form does not store submissions in a database. It opens WhatsApp with the visitor's message pre-filled; the visitor must press Send in WhatsApp for the business to receive it. For private feedback storage, connect a backend or form service later.
